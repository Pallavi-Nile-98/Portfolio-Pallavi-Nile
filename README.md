# Portfolio Website - Pallavi Nile

A professional portfolio website showcasing my experience as a Software Engineering Co-Op at The Geode Foundation, specializing in AI-powered backend systems, blockchain applications, and full-stack development. This static website is optimized for GitHub Pages hosting and features an interactive AI chatbot for enhanced user engagement.

## Overview

This portfolio website serves as a comprehensive showcase of my professional experience, technical skills, projects, and educational background. The site is built using modern web technologies with a focus on performance, accessibility, and user experience. It includes an innovative AI-powered chatbot that demonstrates my expertise in natural language processing and interactive web applications.

## Deployment

### GitHub Pages Deployment

This portfolio is deployed using GitHub Pages, which provides free static website hosting:

1. Repository Setup
   - Push code to GitHub repository
   - Repository name: Portfolio-Pallavi-Nile
   - Main branch contains all source files

2. GitHub Pages Configuration
   - Navigate to repository Settings
   - Select Pages section
   - Choose main branch as source
   - Select root directory
   - Save configuration

3. Automatic Deployment
   - GitHub Pages automatically builds and deploys on each push
   - Build process takes 1-2 minutes
   - Site is accessible at: https://pallavi-nile-98.github.io/Portfolio-Pallavi-Nile/

### Custom Domain (Optional)
- Configure custom domain in repository settings
- Update DNS records with domain registrar
- GitHub Pages supports custom domains with SSL

### Local Development
1. Clone the repository
2. Open index.html in a web browser
3. For testing with local server, use:
   ```bash
   python -m http.server 8000
   ```
   or
   ```bash
   npx serve
   ```

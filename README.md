## 🚀 Features

- **Modern Design**: Clean, professional layout with smooth animations
- **Fully Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- **Fast Loading**: Optimized static site with minimal dependencies
- **SEO Friendly**: Proper meta tags and semantic HTML

## 📦 Deployment to GitHub Pages

### Method 1: Automatic Deployment (Recommended)

1. **Push your code to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/Portfolio-Pallavi-Nile.git
   git push -u origin main
   ```

2. **Enable GitHub Pages**:
   - Go to your repository on GitHub
   - Click on **Settings** tab
   - Scroll down to **Pages** section
   - Under **Source**, select **main** branch (or **master** if that's your default branch)
   - Select **/ (root)** folder
   - Click **Save**

3. **Your site will be live at**:
   ```
   https://YOUR_USERNAME.github.io/Portfolio-Pallavi-Nile/
   ```

### Method 2: Using GitHub Actions (Optional)

If you want to use a custom domain or have more control, you can set up GitHub Actions workflow.

## 🎨 Customization

### Update Personal Information

1. **Contact Details**: Edit the contact section in `index.html`
2. **Social Links**: Update LinkedIn and other social media links
3. **Profile Image**: Replace the placeholder icon with your actual photo
   - Add your image to the project folder
   - Update the `.image-placeholder` div in `index.html` to use an `<img>` tag

### Change Colors

Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    /* ... other colors */
}
```

### Add Projects

Add new project cards in the projects section of `index.html` following the existing structure.
